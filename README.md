# DobbyFetch — Public API Verification Documentation

This repository hosts the public technical documentation and internal data processing / privacy policy for **DobbyFetch**, a private, on-premise Business Intelligence (BI) and Data Warehouse (DWH) platform operated exclusively by **POL-ENSA Sp. z o. o.**

DobbyFetch is a non-commercial, single-organization internal tool used strictly by authorized employees (~10 users) for sales analytics, inventory management, and financial reporting. It is **not** a public SaaS product and does not sell, license, or share data with third parties.

## Published Documentation

- **Technical Overview & API Scope:** https://mahonii223.github.io/dobbyfetch-docs/
- **Internal Data Processing & Privacy Policy:** https://mahonii223.github.io/dobbyfetch-docs/privacy.html

## Contents

- `index.html` — Technical architecture overview, read-only API integration scope (Allegro REST API, Shopify Admin API, Google Ads API, and internal ERP/WMS systems), security controls, and data retention policy (with Polish compliance summary).
- `privacy.html` — GDPR / RODO-aligned Internal Data Processing & Privacy Policy.

> **Note:** This repository contains static public documentation only. No application source code, credentials, or operational data are stored here.
